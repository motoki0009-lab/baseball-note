野球成績ノート（オフライン対応・ホーム画面アプリ版）
==========================================================

このフォルダの中身を、そのままWebに公開するだけで使えます。
サーバーや会員登録は不要で、記録はそれぞれのiPhoneの中にだけ保存されます。

■ GitHub Pages で公開する（無料）
 1. https://github.com でアカウントを作り、ログインします。
 2. 右上の「＋」→「New repository」で新しいリポジトリを作ります。
    名前は半角英数字で、たとえば baseball-note。公開設定は「Public」にします。
    （無料のプランでは、公開設定が Public のリポジトリでしかPagesを使えません）
 3. 作ったリポジトリのページで「uploading an existing file」（または Add file → Upload files）を選び、
    このフォルダの中身をすべてドラッグして、「Commit changes」を押します。
    index.html、sw.js、manifest.webmanifest、画像3つ、fonts フォルダが
    リポジトリの一番上の階層に並ぶようにしてください。
 4. リポジトリの「Settings」→ 左のメニューの「Pages」を開き、
    Source を「Deploy from a branch」、Branch を「main」「/ (root)」にして「Save」します。
 5. 公開まで最大10分ほどかかります。できあがると、次のようなURLになります。
      https://（あなたのユーザー名）.github.io/baseball-note/
 ※ 公開されるのはアプリの部品だけです。成績などの記録は、あなたのiPhoneの中にしかありません。

■ iPhoneで使い始める
 1. iPhoneのSafariで、上のURLを開きます。
 2. 画面下の共有ボタン（四角から上向きの矢印）→「ホーム画面に追加」→「追加」。
 3. 次からは、ホーム画面のアイコンから開きます。最初は電波のあるところで一度開いてください。
    アプリの「設定」で、オフラインの項目が「準備できました」になれば、ネットなしでも使えます。
 ※ ホーム画面のアプリは、Safariとは別の保存場所を使います。必ずホーム画面のアプリで記録してください。

■ バックアップ（大切です）
 ・記録はiPhoneの中にだけ保存されます。試合のあとに、アプリの「バックアップ」を押してください。
 ・共有画面で「ファイルに保存」→「iCloud Drive」を選ぶと、ファイルが残ります。
 ・iPhoneを替えたときや、記録が空になったときは、設定の「復元」からそのファイルを選ぶと元に戻ります。

■ アプリを更新したいとき
 ・index.html などを同じ名前で上書きして公開し直します。
 ・次にネットにつないでアプリを開いたとき、新しい版が入ります（反映は、もう一度開いたあと）。
